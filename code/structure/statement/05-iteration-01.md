# 반복문

반복문은 순환적인 제어 구조를 말한다.  
대부분의 프로그래밍에서는 `{}` 내에서 실행하는 모든 구조를 가리키는 말로 쓰이기도 한다.

> 반복문은 각 언어들마다 문법이 조금씩 다를 수 있다.   
> `{}`를 보통 `코드블록`이라고 말한다.

## while 사용 가이드
1. 반복문이 얼마나 돌아야 할지 정확히 모른다면 `while`을 사용하자.  
   사용시 2가지 기준으로 결정한다.
   1. 시작 부분에서 조건
   2. 끝 부분에서 조건  
      유연함과 최소한 한 번 실행이 필요시 정하는 방법으로,  
      `do-while`을 이용하거나 `while`에 적절한 상황에 종료 로직을 작성하자.
      ```text
      do {
        // ...
      } while (condition);
      
      // rust 인 경우에 이런식으로도 가능
      loop {
          // ...
          if !condition {
              break;
          }
          // ...
      }
      ```
      > 러스트같은 경우에는 `loop` 문법으로 간단하게 표현이 가능하다.
2. 탈출 지점을 최소한으로, 예측 가능한 위치(루프 시작/끝 근처)에 작성하자.
   ```js
   while (true) {
     if (condition1) {
       break;
     }
     
     // ...
   
     if (condition2) {
        break;
     }
     
     // ...
   }
   ```
   탈출 지점이 여러개로 퍼져있다면 코드를 읽을 때 이해하기가 어려워질 수 있다.
   
   그리고 아래와 같이 중복된 코드가 있을 경우 유지보수에 어려움이 생길 수 있다.
   ```js
   let input = getInput();
   while (input !== "exit") {
      // ...
      input = getInput();
   }
   ```
   
   위의 코드들을 아래로 변경해보자.
   
   ```js
   while (true) {
     let input = getInput();
     if (input === "exit") {
       break;
     }
     // ...
   }
   ```
   > while(true)가 무조건 나쁘다긴 보다는 루프 탈출 지점이 중구난방으로 퍼져있어 안티패턴이 되었다고 생각도 든다.
