# 반복문

## for 사용 가이드
`for`문은 `while`문과 다르게 지정된 횟수가 있을 때 사용한다.
1. foreach 반복문
   현대 많은 언어들은 foreach를 지원하는데 `컬렉션`에 대해 연산 필요시 사용하자.
   ```
   List<String> list = new ArrayList<>();
   for (var str : list) {
        // ...
   }
   ```
   기존 for문보다 더 가독성있게 작성하여 유지보수에 도움을 줄 수 있다.
2. 무한 루프 필요시 `while`과 같은 다른 문법을 사용하자
   ```
   for (;;) {
     // ...
   }
   ```
   for문의 조건들을 모두 빼버려 `while(true)`와 같은 문법도 가능한데,  
   개인적으로는 그 기능을 하기 위한 대체 문법들이 있다면 대체 문법을 사용하는게 좋다고 생각한다.
   > 위 문법을 `forever`이라고도 불렀으며 과거에는 `while(true)`보다 성능이 조금 더 좋았다고 한다.
3. for 헤더 조건은 한눈에 들어오는 수준까지만 적자
   ```
   // 이 정도는 허용
   for (int i = 0; i < count && !found; i++) {
      // ...
   }
   
   // 조건이 늘어나면 몸통의 if/break로 분리
   for (int i = 0; i < count; i++) {
      if (found || timeout || cancelled) {
        break;
      }
      // ...
   }
   ```
   for문의 헤더에 조건이 많아질수록 한눈에 파악하기가 어려운 상황이 많기에,  
   자기만의 기준을 세워 일정 수준을 넘어서면 몸통으로 분리하는 방향을 하거나 `while`문으로 교체를 고려해보자.
