# 네트워크 기초

## 네트워크란?
네트워크란 Net + Work의 합성어로 두 대 이상의 기기가 연결되어  
무언가를 주고받는 시스템의 **집합**을 말한다.

### 인터넷과의 관계
우선 인터넷은 네트워크의 하위 개념이 아니다.  
전 세계의 네트워크들이 **IP**라는 **프로토콜**로 연결되어 만들어진  
거대한 **네트워크**를 의미한다.

### 네트워크 범위
네트워크는 규모(범위)에 따라 분류가 된다.
- PAN (개인 통신망)  
개인에 초점을 맞춘 네트워크로 보통 10m 안 정도의 규모  
> 대표적으로느 블루투스, 적외선 통신 등이 있다.
- LAN (근거리 통신망)
일정 지역 내 사용을 초점을 맞춘 네트워크로 최소 150m 에서 1km 까지 구성을 한다.
> Wifi가 대표적이다.
- MAN (도시 지역 통신망)
근거리에서 더 규모가 커진 것으로 최대 75km 까지 구성
> 케이블 TV망 대표적이다.
- WAN (원거리 통신망)
도시 지역을 넘어 멀리떨어진 지역의 통신망과 연결을 위한 용도.
> 인터넷이 대표적이다.

## OSI 7계층
OSI 7계층은 서로 다른 시스템간 통신을 7단계로 나눈 모델로,  
문제가 생겼을 때 어느 계층에서 발생했는지 파악을 빠르게 하기 위함이다.
- 7계층 : 응용(Application)  
사용자와 직접 상호작용 하는 프로그램들이 해당  
프로토콜 : HTTP, FTP, SMTP, DNS 등  
단위 : 데이터
- 6계층 : 표현(Presentation)  
데이터 형식 변환, 암호화/압축  
단위 : 데이터
- 5계층 : 세션(Session)  
통신 세션 생성/유지/종료  
단위 :  데이터  
- 4계층 : 전송(Transport)  
종단 간 (End-to-End) 신뢰성 있는 전달  
프로토콜 : TCP, UDP  
단위 : 세그먼트
- 3계층 : 네트워크(Network)  
목저지까지 경로 설정 (라우팅)  
프로토콜 : IP, ICMP  
단위 : 패킷
- 2계층 : 데이터링크(Data Link)  
인접 장치 간 전달, 오류 검출  
장비 : 이더넷, MAC 주소  
단위 : 프레임
- 1계층 : 물리(Physical)  
전기/광/무선 신호로 실제 전송 단계  
장비 : 케이블, 허브, 랜칩  
단위 : 비트
